This document contains the weekly workflow audit, custom instructions for the Claude Project, and success definitions for three target tasks to be reused in FL-02 through FL-04.

## 1. Weekly Task Audit

Below is an audit of 12 recurring tasks from a typical week as an ML intern and student, classified by how AI is integrated into the workflow.

| Task | Classification | One-Line Rationale |
| :--- | :--- | :--- |
| **1. Learning core ML concepts (e.g., bias-variance trade-off)** | **Just Me** | I need to build deep intuition in my own brain; shortcuts won't help me pass interviews or exams. |
| **2. Reviewing code changes and security flags** | **Just Me** | Evaluating code security and business logic requires ultimate accountability and human judgment. |
| **3. Writing initial Python scripts for data cleaning** | **Collaborate** | The AI writes the boilerplate structure, and I refine the logic and match it to our data contract. |
| **4. Formatting raw test data tables into Markdown** | **Delegate + Review** | AI is highly efficient at structural formatting, requiring only a quick check for accuracy. |
| **5. Running pipeline evaluation scripts (`run_all.py`)** | **Fully Automate** | A single terminal script runs the entire sequence, requiring no manual step-by-step guidance. |
| **6. Troubleshooting syntax and library installation errors** | **Collaborate** | I share the stack trace with AI to find solutions, then manually run and test the suggestions in my terminal. |
| **7. Reading and analyzing SEO research papers** | **Just Me** | Building deep domain context and connecting concepts requires active, focused human reading. |
| **8. Drafting weekly progress updates for mentors** | **Delegate + Review** | The AI writes a polite, structured email from bullet points, which I personalize and edit before sending. |
| **9. Creating visualization charts (e.g., matplotlib/seaborn)** | **Collaborate** | AI writes the plotting commands, and I manually adjust details like color palettes and labels. |
| **10. Writing SQL queries to extract raw dataset columns** | **Collaborate** | AI helps draft complex JOINs, which I verify against the database schema for correct column mappings. |
| **11. Creating mock data for unit tests** | **Delegate + Review** | AI quickly generates synthetic JSON or CSV rows, which I verify to ensure boundary cases are met. |
| **12. Documenting function signatures and docstrings** | **Delegate + Review** | AI generates clear docstrings from function code, and I review them for clarity. |

## 3. Target Tasks and Success Definitions

These three tasks will be reused and evaluated in FL-02 through FL-04:

### Task A: Data Cleaning and Feature Preparation Script
* What "Done Well" Means (Measurable Criteria):
  1. The Python script executes end-to-end without warnings or errors.
  2. All missing values in numeric features are filled using the median value of the column.
  3. The final output is saved as a clean CSV file, containing exactly the columns specified in the data contract.

### Task B: Implementing a Rule-Based Baseline Model
* What "Done Well" Means (Measurable Criteria):
  1. The model function takes a DataFrame as input and returns a ranked list of pages.
  2. The ranking is built using a simple, transparent rule (e.g., sort by trend magnitude) and contains no future-leakage columns.
  3. The script outputs the baseline precision score and records it in a committed JSON metrics file.

### Task C: Model Performance Evaluation and Report
* What "Done Well" Means (Measurable Criteria):
  1. The script generates a Markdown summary comparing the machine learning model against the baseline.
  2. It includes a confusion matrix and lists precision, recall, and F1-score.
  3. All metric values match the figures generated by the corresponding notebook exactly.
